# 티끌모아 태산

> 내가 쓴 돈을 **전날 종가 기준으로 주식을 소수점 매수했다면** 지금, 그리고 1년 뒤 얼마가 됐을지 보여주는 앱.
> 목표: 불필요한 소비를 스스로 돌아보고, 작은 돈이라도 투자하는 습관을 만든다.

## 바로 쓰기
👉 **https://ghjkl248.github.io/tiklmoa/**

휴대폰 홈 화면에 앱처럼 설치하기
- **아이폰(사파리)**: 공유 버튼 → "홈 화면에 추가"
- **안드로이드(크롬)**: 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"

기록은 각자의 기기(브라우저)에만 저장되며 서버로 전송되지 않습니다.

## 내 PC에서 실행(개발용)
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
브라우저에서 http://localhost:8037 을 엽니다. 설치할 것은 없습니다(순수 HTML/CSS/JS).

## 현재 기능 (MVP · 가상 투자)
| 기능 | 내용 |
|---|---|
| 소비 기록 | 금액·사용처·카테고리·날짜 입력 → 지정 종목을 **전날(직전 거래일) 종가 × 환율**로 소수점 매수한 것으로 기록 |
| 카드 알림 연동 | 카드 승인 문자를 붙여넣으면 금액·날짜·가맹점을 읽어 여러 건을 한 번에 등록(승인취소는 제외) |
| URL 연동 | `index.html?amount=5000&merchant=스타벅스&date=2026-11-15` 형식의 주소로 기록 시트를 바로 엽니다 → 휴대폰 단축어·자동화 앱 연결용 |
| 종목 | 지수 ETF 6 · 배당 ETF 5 · 시가총액 상위 개별주 39 = **50종목** (`js/universe.js`) |
| 카테고리별 종목 | 예: 커피는 SCHD, 배달은 QQQ |
| 시세 변동·배당 | 날짜마다 주가가 변하고, 배당락일마다 배당(미국 원천징수 15% 반영)을 지급. 재투자(DRIP)와 현금 보유 중 선택 |
| 1년 뒤 | 소비 1건마다 소비일+1년 시점의 가치(아직 1년이 안 됐으면 기대수익률로 추정), 카테고리별 비교, 습관을 유지할 때의 1·3·5·10·20년 적립 결과, 계산기 |

## 시세 데이터
- 기본값은 **샘플 시세**입니다. 종목마다 기준가(`ANCHOR_DATE` 종가로 가정)에서 결정론적 모의 시세를 만들기 때문에 실제 주가와 다릅니다.
- 설정에서 **Finnhub 무료 API 키**를 넣으면 실제 전날 종가에 맞춰 보정합니다. 환율은 `open.er-api.com`에서 자동으로 받거나 직접 입력할 수 있습니다.

## 구조
```
index.html        화면 뼈대
css/style.css     스타일 (상승 빨강/하락 파랑, 다크모드)
js/universe.js    종목 50개, 소비 카테고리
js/engine.js      날짜, 모의/실시간 시세, 배당, 평가, 1년 뒤 계산
js/store.js       저장(localStorage), 카드 문자 파서, URL 연동, 예시 데이터
js/app.js         화면 렌더링·이벤트
serve.ps1         로컬 미리보기 서버
```

## 다음 단계 후보
1. **호스팅 + PWA**: GitHub Pages 등에 올려 홈 화면에 설치. 그래야 휴대폰에서 URL 연동을 쓸 수 있습니다.
2. **카드 자동 연동**

   - 안드로이드: 알림 읽기 앱(MacroDroid 등) 또는 네이티브 앱의 알림 접근 권한
   - 마이데이터 API는 사업자 인가가 필요합니다.
3. **실시간·과거 시세 백엔드**: 실제 과거 종가와 배당 이력 저장
4. **실제 매수**: 증권사 Open API(해외주식 소수점 주문)에 연결. 본인 계좌 자동화만 가능하며, 타인 대상 서비스는 투자일임·중개 인가가 필요합니다.
